# Sagban «дисциплинатор» боти (@sagban_yr_bot)

Гуруҳ: «Сагбан дистр (ОНЛАЙН ОФИС)». Бот фақат Python'нинг ўзида ёзилган,
қўшимча кутубхона керак эмас.

## Нима қилади

**1-вазифа.** Якшанбадан ташқари ҳар куни соат 09:00 да (Тошкент вақти)
«Кунлик режа» мавзусига шу кўринишда рўйхат юборади:

```
Кунингиз Барокатли булсин!
Иш вактини бошлади:
1. 07:56:28 - Муаззам
2. 08:43:09 - Севарахон С12
...

Ишга келмаганлар (09:00 гача видео ташламаганлар):
- Умидахон О2
```

Ходим кун давомида биринчи марта видео ташлаган вақти ёзилади.
09:00 дан кейин ташланган видео рўйхатга кирмайди.
«Ишга келмаганлар» бўлимини ўчириш учун `config.json` да
`"show_missing": false` қилинг.

## Ишга тушириш (Windows)

1. Python ўрнатинг: https://www.python.org/downloads/ («Add python.exe to PATH» белгисини қўйинг).
2. Шу папкани компьютерга кўчиринг.
3. `config.example.json` файлидан нусха олиб `config.json` деб номланг ва
   ичидаги `"token"` қаторига BotFather берган токенни ёзинг.
4. Папкада `cmd` очиб ёзинг:
   ```
   python bot.py
   ```
5. Ойна очиқ турса бот ишлайди. Ёпилса тўхтайди. Доимий ишлаши учун
   серверда ёки ўчмайдиган компьютерда қолдиринг.

Linux серверда: `nohup python3 bot.py &` ёки systemd хизмати.

## Буйруқлар (фақат админ учун)

| Буйруқ | Нима қилади |
|---|---|
| `/mavzu` | Шу мавзуни «Кунлик режа» деб белгилайди (гуруҳда, ўша мавзунинг ичида ёзилади). Бир марта қилинади. |
| `/hisobot` | Бугунги рўйхатни ҳозироқ чиқаради. `/hisobot 2026-10-20` — ўша куннинг рўйхати. |
| `/biriktir 5` | Ходимнинг хабарига reply қилиб ёзилади: ўша одамни рўйхатдаги 5-ходимга бириктиради. Исм билан ҳам бўлади: `/biriktir Муаззам`. |
| `/xodimlar` | Ходимлар рўйхати ва ким танилгани. |
| `/ping` | Бот ишлаяптими. |

Бот ходимларни Telegram'даги исмига қараб ўзи танийди (лотинча ёзилган
бўлса ҳам). Таниёлмаса (масалан исми фақат эмоджи бўлса) админга шахсий
хабар юборади, админ `/biriktir` билан бир марта бириктиради.

## Файллар

- `bot.py` — ботнинг ўзи.
- `config.json` — созламалар, токен, ходимлар рўйхати (git'га кирмайди).
- `data.json` — ким қачон видео ташлагани (git'га кирмайди).

## Энг осон йўл (Windows)

`start.bat` файлини икки марта босинг. У ботни ишга туширади ва бот
тўхтаб қолса 10 сониядан кейин ўзи қайта ишга туширади. Ойнани ёпсангиз
бот тўхтайди.

Компьютер ёқилганда ўзи ишга тушиши учун: `Win + R` → `shell:startup` →
очилган папкага `start.bat` нинг ярлиғини (shortcut) қўйинг.
