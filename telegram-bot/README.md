# Sagban «дисциплинатор» боти (@sagban_yr_bot)

Гуруҳ: «Сагбан дистр (ОНЛАЙН ОФИС)». Бот фақат Python'нинг ўзида ёзилган,
қўшимча кутубхона керак эмас.

## Нима қилади

**1-вазифа.** Якшанбадан ташқари ҳар куни соат 09:00 да (Тошкент вақти)
«Кунлик режа» мавзусига шу кўринишда рўйхат юборади:

```
Кунингиз Барокатли булсин!
Иш вактини бошлади:
1. 07:56:28 - Муаззам
2. 08:43:09 - Севарахон С12
...

Ишга келмаганлар (09:00 гача видео ташламаганлар):
- Умидахон О2
```

Ходим кун давомида биринчи марта видео ташлаган вақти ёзилади.
09:00 дан кейин ташланган видео рўйхатга кирмайди.
«Ишга келмаганлар» бўлимини ўчириш учун `config.json` да
`"show_missing": false` қилинг.

**2-вазифа.** Ҳар бир ходим шу мавзуга кунлик ҳисоботини матн билан
22:00 гача ёзиши керак. Якшанбадан ташқари ҳар куни 22:00 да бот мавзуга
ёзмаганлар рўйхатини чиқаради:

```
Кунлик хисобот ёзмаганлар:
1. Дилшодахон Сгб
2. Умидахон О2
```

ва ҳар бирига шахсий хабар юборади: «Хисобот ёзмаганизи эслатиб утаман».
Telegram қоидаси: бот шахсий хабарни фақат ботга бир марта **Start**
босган одамга юбора олади. Ходимлар @sagban_yr_bot га кириб Start
босишлари керак; босмаганларни бот админга шахсий хабарда айтади.
`report_min_chars` дан (10 белги) қисқа хабар ҳисобот деб саналмайди.

**3-вазифа.** «Дуконлар расми» мавзусида ҳар бир ходим бир кунда нечта
расм ташлаганини санайди (альбом, яъни бир хабардаги бир нечта расм, 1 та
деб саналади) ва якшанбадан ташқари ҳар куни 18:00 да ўша
мавзуга рўйхат чиқаради:

```
Бугунги дўконлар расми (жами 23 та):
1. Муаззам — 12 та
2. Севарахон С12 — 7 та
3. Дилшодахон Сгб — йўқ
```

Мавзуни бот номидан ўзи топади (`photo_topic_name`), унда биринчи хабар
келиши билан. `/rasmlar` билан исталган пайт кўрилади, `/kunlar` да ҳам
чиқади. `/mavzular` бот кўрган мавзуларни ва уларнинг ID ларини кўрсатади.

**Яна:**
- Ҳар куни 07:00 ва 17:00 да админга шахсий «Бот тайёр ✅» хабари келади.
  17:00 дагисида ботга Start босмаган ходимлар рўйхати ҳам бўлади. Хабар
  келмаса, бот ишламаяпти.
- Кунлик ҳисобот деб фақат ичида «отчёт» (ёки отчет, otchet, ҳисобот,
  hisobot) сўзи бор хабар саналади (`report_keywords`).
- `/dam` билан белгиланган кунларда ҳеч қандай рўйхат чиқмайди.
- Ҳар ойнинг 1-куни 10:00 да админга ўтган ойнинг умумий жадвали келади
  (келди / келмади / ҳисобот йўқ / расмлар). Бот маълумот йиға бошлаган
  кундан бошлаб ҳисобланади.

## Ишга тушириш (Windows)

1. Python ўрнатинг: https://www.python.org/downloads/ («Add python.exe to PATH» белгисини қўйинг).
2. Шу папкани компьютерга кўчиринг.
3. `config.example.json` файлидан нусха олиб `config.json` деб номланг ва
   ичидаги `"token"` қаторига BotFather берган токенни ёзинг.
4. Папкада `cmd` очиб ёзинг:
   ```
   python bot.py
   ```
5. Ойна очиқ турса бот ишлайди. Ёпилса тўхтайди. Доимий ишлаши учун
   серверда ёки ўчмайдиган компьютерда қолдиринг.

Linux серверда: `nohup python3 bot.py &` ёки systemd хизмати.

## Бот ўчиб қолса

Бот белгиланган вақтда ишламаган бўлса (компьютер ухлаган, ойна ёпилган),
қайта ишга тушганда аввал ўтказиб юборган хабарларни ўқийди, кейин
ҳисоботни кечикиб бўлса ҳам юборади: эрталабкисини 22:00 гача, кечкисини
ярим тунгача. Хабар охирида «⏰ Кечикиб юборилди» деб белгиланади.
Ўтган кунлар учун рўйхат `/kunlar` орқали кўрилади.

Компьютер ухлаб қолмаслиги учун: Settings → System → Power & battery →
Screen and sleep → «When plugged in, put my device to sleep after» → **Never**.

## Интернет секин ёки узилиб турса

Бот Telegram серверига битта уланишни очиб ушлаб туради ва узилса ўзи
қайта уланади. Агар `api.telegram.org` компьютерингиздан умуман очилмаса
ёки доим "handshake timed out" чиқса, `config.json` да прокси кўрсатинг:

```
"proxy": "http://host:port"
"proxy": "socks5://user:parol@host:port"
```

SOCKS прокси учун бир марта `pip install pysocks` керак. Telegram Desktop
созламаларида ишлатаётган проксингизни шу ерга ёзсангиз бўлади.

## Ойна билан ишлатиш (Windows)

`start.bat` файлини икки марта босинг. У ботни ишга туширади ва бот
тўхтаб қолса 10 сониядан кейин ўзи қайта ишга туширади. Ойнани ёпсангиз
бот тўхтайди.

Компьютер ёқилганда ўзи ишга тушиши учун: `Win + R` → `shell:startup` →
очилган папкага `start.bat` нинг ярлиғини (shortcut) қўйинг.
